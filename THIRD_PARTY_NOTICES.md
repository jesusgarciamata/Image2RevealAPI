# Componentes de terceros

Organic Reveal API instala y utiliza los siguientes componentes principales:

- SAM 2, Meta Platforms, Inc., licencia Apache 2.0. Revisión fijada: `2b90b9f5ceec907a1c18123530e92e794ad901a4`.
- Checkpoint `facebook/sam2.1-hiera-tiny`, distribuido por Meta junto con SAM 2.
- PyTorch y TorchVision, licencia BSD-style.
- OpenCV, licencia Apache 2.0.
- FFmpeg y el codificador disponible en la distribución Debian. Las obligaciones concretas dependen de la configuración y del uso que se haga de la imagen.

Consulta las licencias originales de cada proyecto antes de redistribuir públicamente una imagen Docker. Este archivo es informativo y no constituye asesoría legal.
